# 个人网站 · 使用说明

## 文件结构
- `index.html` —— 网站本体（版式、配色、动效都在这里，**一般不用动**）
- `content.js` —— **所有文字内容**（你只需要改这个文件）
- `使用说明.txt` —— 本文件

## 怎么改内容（3 步）
1. 用记事本 / VS Code 打开 `content.js`
2. 找到要改的字段，改双引号里的文字，保存
3. **强制刷新浏览器**（Ctrl + Shift + R / Mac: Cmd + Shift + R）即可生效

> 为什么要强制刷新：浏览器会缓存文件，普通 F5 看到的是旧版本。

## 怎么预览
三种方式都可以（顺序不分先后）：

- **方式 A（最简单）**：直接双击 `index.html`，浏览器会打开并显示
- **方式 B**：在文件夹内运行 `python -m http.server 8000`，浏览器访问 `http://localhost:8000`
- **方式 C**：用 VS Code 装 "Live Server" 插件，右键 index.html → Open with Live Server（改完自动刷新）

## 常用改法示例

**补上 Depology 的待补数据：**
找到 `"pending"` 字段（默认空），填上文字即可显示黄色胶囊：
```js
"pending": "跑量广告存活率 2.8% → 18%"
```
不需要显示的话把内容清空：`"pending": ""`

**挂上白皮书 / 项目链接：**
```js
"link": "https://example.com/白皮书.pdf",   // 网址
"linkText": "阅读 PDF →"                      // 链接上显示的字
```
填了 `link` 之后 `linkText` 会自动变成可点击的链接；不填 `link` 就是普通说明文字。

**加 / 删一段工作经历：**
在 `jobs` 数组里复制粘贴一段 `{ ... }`，改 `company / period / stats` 即可。每行末尾的逗号是允许的。

## 文字加粗 / 高亮
```html
<b>要加粗的字</b>
<span class='hl'>要高亮的字</span>
```

## 怎么发布上线（免费）
1. 把整个文件夹推到 GitHub 仓库
2. 仓库 Settings → Pages → 选 main 分支 → 保存
3. 1 分钟后访问 `https://用户名.github.io/仓库名/`

（或者 vercel.com：拖拽文件夹即可部署，更快）

## 常见问题

**Q：改了文件但页面没变？**
A：用 Ctrl + Shift + R 强制刷新（绕过浏览器缓存）。

**Q：双击打开后页面是空的？**
A：用 VS Code 或专业编辑器打开 `content.js`，注意：
- 头尾两行别删：`window.SITE_CONTENT = {`  和 `};`
- 每个 `{ }` `[ ]` 都要成对出现
- 文件末尾必须以 `};` 结尾
- JS 允许数组 / 对象末尾多余逗号，比 JSON 宽松

**Q：想加新的板块（比如证书、推荐信）？**
A：告诉我，我来加。
